# The look kit

Each day the reels get a new **look**: a visual identity laid over the same scenes. A look is
one file in `catalog/` (data) plus the effects it picks from `fx/` (code). The day's reels name
it in `plan.json` → `reel.style`. No `style` = the classic look, which must never change (the
manual studio's reels and every older episode use it).

## What a look sets (`types.ts`)

| Field | What it changes | Options today |
|---|---|---|
| `palette` | every colour slot (`green` = main accent, `red` = alerts, `gold` = rewards, `teal` = tech, `pink`+`orange` = brand gradient, `magenta`, `navy`) | any hex |
| `fonts` | `display` (big words, captions), `brand` (kickers, top bar, card names), `mono` (labels, chips), `arabic` | the table below |
| `displayWidth` | letter width of the display font; big words shrink to fit | the table below |
| `ink` | text on accent chips | dark if the accent is light |
| `captions` | `style`, `size`, `y`, `font`, `active` (palette slot) | `stroke` `box` `karaoke` `tape` `stack` |
| `hud` | the top bar | `bar` `tape` `case` `ticker` `minimal` |
| `finish` | full-frame overlays, in order | `vignette` `scanlines` `grain` `vhs` `halftone` `paper` `lightleak` `dust` `crt` `bloom` |
| `grade` | the gameplay's colour: `filter`, `tint`+`blend`+`amount`, `duotone` | CSS |
| `cut` | an overlay on every cut between scenes | `none` `flash` `shutter` `whip` `glitch` `iris` `ink` |
| `enter` | how a scene's content arrives | `zoomblur` `slide` `rise` `snap` |
| `title` | how big words are drawn | `glitch` `chrome` `outline` `neon` `print` |
| `series` | tweaks per format, e.g. `{"GTA 6 NEWS": {hud: {style: 'ticker'}}}` | any of the above |

## Fonts (all open licence, in `public/fonts`, registered in `src/fonts.ts`)

Display faces, with the `displayWidth` to use (Anton = 0.47; wider fonts make big words smaller):

| Family (CSS name) | displayWidth | Feel |
|---|---|---|
| `Anton` | 0.47 | classic poster |
| `'Bebas Neue'` | 0.39 | tall, clean, 80s |
| `'Big Shoulders Black'` | 0.47 | industrial, condensed |
| `'Barlow Condensed ExtraBold'` | 0.48 | sporty, condensed |
| `'Oswald Bold'` | 0.54 | tabloid headline |
| `'Space Grotesk Bold'` | 0.62 | modern tech |
| `Righteous` | 0.64 | rounded retro |
| `'Russo One'` | 0.69 | racing |
| `'Playfair Display Black'` | 0.70 | serif masthead |
| `Bungee` / `'Black Ops One'` | 0.71 | signage / stencil |
| `'Archivo Black'` | 0.77 | heavy grotesk |
| `'Rubik Mono One'` | 0.96 | wide, blocky (accents only) |
| `Monoton`, `Pacifico` | — | neon outline / script: short accents only, never captions |

`brand` must be no wider than Unbounded (the classic brand font): Unbounded, Space Grotesk Bold,
Righteous, Russo One, Playfair Display Black, Black Ops One, Bungee, Oswald Bold all fit;
`'Syne ExtraBold'` and `'Rubik Mono One'` are too wide for kickers and wrap.

Mono: `"JetBrains Mono"`, `VT323` (VHS), `'Special Elite'` (typewriter), `'IBM Plex Mono Bold'`,
`'Space Mono Bold'`, `'Press Start 2P'` (pixel, very wide: short labels only).

Arabic: `Tajawal`, `Cairo`, `Lalezar`, `Rakkas`, `'Reem Kufi Bold'`, `'Changa Bold'`,
`'El Messiri Bold'`, `'Marhey Bold'`, `'Noto Kufi Arabic Black'`.

To add a font: download an open-licence font (google/fonts on raw.githubusercontent.com works),
put it and its licence in `public/fonts`, register it in `src/fonts.ts` (a variable font under a
"Family Weight" name pinned to one weight), measure its width like the table.

## Adding new effects

New code goes in `fx/` as a **new option** (a new caption style, top bar, finish, cut, title
style, or a skin for a scene), added to the union in `types.ts` and to the map in its fx file.
Never change what an existing option draws: older reels re-render with it.

Keep it cheap, it runs on every frame: CSS gradients, a few divs, `random()`/`noise2D()` for
motion. At most one full-frame SVG filter per look. Textures are generated by
`reels/tools/textures.py`, never downloaded.

## Check a look

```bash
cd reels && npx tsc --noEmit && cd ..
python reels/tools/look.py <look-id>          # → out/looks/<look-id>.jpg, frames of the newest episode
python reels/tools/look.py <look-id> --frames 96,98,100,102   # around a cut
```
